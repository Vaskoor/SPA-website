# Thamel Spa & Wellness – Full‑Stack Application

A modern spa management system with a **React (Vite) frontend** and a **Laravel 10 (API) backend**.  
Includes client booking, practitioner management, admin dashboard, multi‑currency, multi‑language, and more.

---

## 🚀 Quick Start

### Prerequisites

- **PHP ≥ 8.1** + [Composer](https://getcomposer.org/)
- **Node.js ≥ 18** + npm / yarn
- **MySQL** (or any database supported by Laravel)
- **Git**
